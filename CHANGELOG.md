# Changelog

## 0.1.0 (unreleased)

### Before you upgrade

**A migration is required.** This build ships 53 migration files (this is the first release, so every one of them is new), up to `0053_command_idempotency.sql`. Migrations are forward-only and are applied by the `migrate` service under an advisory lock:

```bash
docker compose exec -T db pg_dump -U app -Fc app > pre-upgrade-$(date +%F).dump
docker compose run --rm migrate
docker compose up -d
```

**Take the dump first.** A migration is forward-only, so there is no down-step if one goes wrong, and rolling the image back without rolling the database back is not supported: a build refuses to start against a database carrying a migration it does not know, and names it. See `docs/operator-guide.md` § 5 (upgrade) and § 6 (backup).

### What has not been measured

**The prompts in this release have never been run against a model.** TD-016’s role evals and the nightly real-LLM smoke (evals.yml, nightly-llm.yml) are not in this build: they need a model credential the repository does not have (WP-33). Every automated tier that gates this release is deterministic — the agent in them is a fake. The prompt assembly, the tool policy and the artifact schemas are tested; **what a model does with them is not.**

### What this release does not claim

This is the first release of the **mechanism** — the images, the migrations, the changelog and
the tags. It is not a claim that the MVP is finished. product/14’s exit criteria, each with
what this repository can say about it:

- *“20 real tickets across the 2 founder projects”* — **not evidenced**: no ticket has been delivered by an installation of this build; `/api/org/stats` is where the count comes from once one has.
- *“≥ 60% merged”* — **not evidenced**: the statistics API computes it from delivered tasks; it has none.
- *“cost per merged feature measured”* — **not evidenced**: the cost ledger records a run’s reported spend, and no run of this build has been merged.
- *“≥ 10 accepted KB proposals”* — **not evidenced**: nothing has been proposed or accepted; the queue exists.
- *“zero secrets incidents”* — **evidenced for this repository only**: gitleaks runs over the full history in CI and over every staged diff in the pre-commit hook, and has never reported a finding here. That is a statement about **this repository**, not about any installation — an incident in an instance is not something a release can evidence.
- *“a stranger can install from the README in < 1 hour”* — **not evidenced**: the operator guide was written against a dogfood install and every command in it was run, by the author of the software — which is not the measurement.
- *“shadow mode run on 10 closed tickets per project with a comparison report”* — **not evidenced**: shadow mode and its report ship in this build; no batch has been run on a real project.
- *“review-only used on ≥ 20 human MRs”* — **not evidenced**: review-only ships and is off by default; no project has enabled it.
