# BD-015 — The web UI is a first-class control tower; humans still work in their tools

- **Status:** accepted
- **Date:** 2026-08-28
- **Relates to:** product/10

## Decision
Invest in a polished, real-time web UI for visibility (board, agents, run transcripts), governance (budgets, audit, statistics) and configuration (pipelines, prompts, integrations, knowledge). Day-to-day interaction with tasks (questions, review, merge) stays in Jira, GitLab and Slack, with the UI as an equivalent channel.

## Rationale
Trust in autonomy comes from visibility; but forcing people into a new tool for routine actions kills adoption.
